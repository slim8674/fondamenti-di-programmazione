# Fondamenti di Programmazione

Repository pubblica del mio percorso di studio di **Fondamenti di Programmazione in Python** presso **Sapienza Università di Roma**.

La repository viene costruita e aggiornata in modo progressivo seguendo le lezioni del corso universitario, mantenendo una struttura semplice e aderente agli argomenti affrontati a lezione.

## Contenuto

All'interno della repository raccolgo materiale di studio relativo al corso, in particolare:

- appunti
- esempi di codice
- piccoli esercizi
- materiale di ripasso

## Struttura

La struttura della repository è volutamente essenziale.

```text
lezioni/
└── 01/
    ├── appunti.md
    └── esercizi.py
```

Ogni cartella dentro `lezioni/` corrisponde a una lezione o a un piccolo blocco di lezioni.

## Obiettivo

L'obiettivo della repository è organizzare il materiale del corso in modo chiaro, ordinato e progressivo, così da avere una traccia del percorso di studio e un archivio facilmente consultabile.

## Metodo

La repository cresce passo passo insieme al corso.

Per ogni lezione vengono aggiunti, quando utile:

- appunti sintetici sui concetti trattati
- esempi scritti in Python
- piccoli esercizi per consolidare la teoria

## Tecnologie utilizzate

- **Python**
- **Markdown**

## Nota

Questa repository nasce come supporto personale allo studio, ma viene resa pubblica come documentazione del percorso svolto durante il corso di **Fondamenti di Programmazione**.
